# 📖 Sobre o Projeto

O **Sistema de Cliente** é uma aplicação desenvolvida para gerenciamento de informações de clientes, permitindo a implementação de funcionalidades relacionadas ao cadastro, consulta, atualização e manutenção de registros.

Durante o desenvolvimento do projeto, foram aplicados conceitos fundamentais de engenharia de software, organização de código, controle de versões com Git e fluxo de trabalho utilizando múltiplas branches.

Além do desenvolvimento da aplicação, o projeto serviu como prática para o uso de metodologias de evolução incremental, permitindo a separação entre novas funcionalidades e desenvolvimento da interface.

# 🌳 Estrutura de Branches

O projeto está dividido em duas branches principais, cada uma com responsabilidades específicas.

| Branch | Finalidade |
|----------|----------|
| **Front** | Desenvolvimento e evolução da interface do sistema |
| **NewFeatures** | Implementação de novas funcionalidades e melhorias |

### 🔹 Branch Front

A branch **Front** foi criada para concentrar o trabalho relacionado à interface da aplicação.

Principais objetivos:

- Desenvolvimento das telas.
- Ajustes visuais.
- Melhorias de usabilidade.
- Estruturação da experiência do usuário.
- Integração com funcionalidades existentes.

### 🔹 Branch NewFeatures

A branch **NewFeatures** foi criada para o desenvolvimento de novos recursos e evolução da aplicação.

Principais objetivos:

- Implementação de novas funcionalidades.
- Correções de bugs.
- Melhorias de desempenho.
- Refatoração de código.
- Evolução das regras de negócio.

Essa organização permite um fluxo de desenvolvimento mais próximo ao utilizado em equipes profissionais, facilitando testes, manutenção e futuras integrações.

# ⚙️ Como Executar o Projeto

## 1. Clonar o Repositório

```bash
git clone https://github.com/luisshenri/SistemaDeCliente.git
```

## 2. Acessar o Diretório

```bash
cd SistemaDeCliente
```

## 3. Verificar as Branches Disponíveis

```bash
git branch -a
```

## 4. Acessar a Branch Front

```bash
git checkout Front
```

## 5. Acessar a Branch NewFeatures

```bash
git checkout NewFeatures
```

## 6. Executar o Projeto

A forma de execução pode variar de acordo com a branch utilizada e as tecnologias implementadas.
